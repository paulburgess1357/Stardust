*stardust.txt*  A quiet night sky for Neovim

Stardust requires Neovim 0.10 or newer.                     *stardust*

SETUP                                                    *stardust-setup*
>lua
  vim.opt.runtimepath:prepend('/home/paul/Repos/Stardust')
  require('stardust').setup({ autostart = true })
<
For the complete option list and compatibility notes, see README.md.
All highlight groups set foreground colors only, preserving transparency.

COMMANDS                                                 *:Stardust*

  :Stardust              Toggle the animation.
  :Stardust start        Start the animation.
  :Stardust stop         Stop and clear all decorations.
  :Stardust meteor       Attempt a meteor in the current view.
  :Stardust status       Show activity and skipped-window reasons.
  :checkhealth stardust  Check rendering requirements.

LUA                                                      *stardust-api*

  require('stardust').setup(opts)
  require('stardust').start()
  require('stardust').stop()
  require('stardust').toggle()
  require('stardust').meteor()  -- boolean: whether a clear path was found
  require('stardust').status()  -- table: activity, counts, skipped views

SAFETY                                                   *stardust-placement*

Text is checked on every redraw. Indentation and blank buffer lines are
reserved by default; blank_lines=true enables stars on blank buffer lines.
Wrap, diff, conceal, visible folds, and external virtual lines disable the
effect for the affected view. Terminals and floating windows are skipped.

The below-EOF canvas is shared by all views of a buffer and sized to their
smallest free area. Set below_eof=false to disable it independently.

Set b:stardust_disable or w:stardust_disable to v:true to exclude a buffer
or window. Temporary decorations from arbitrary third-party redraw providers
cannot always be inspected; use these exclusions where needed.
